# EECE435L Lab 6 Automatic Build

Hassan Nasrallah

This submission contains the required calculator project built with PyBuilder,
plus the optional greeting project automated using PyBuilder and GNU Make.

| Folder | Contents |
| --- | --- |
| `calculator_Hassan_Nasrallah/` | Graded exercise: seven arithmetic operations, 32 unit tests, build.py, and packaging metadata. |
| `my_python_project/` | Optional exercise: greeting application, four unit tests, build.py, and Makefile. |
| `evidence/` | Actual build logs, test reports, package verification, and terminal screenshot. |

Each project has a README with setup commands and a brief explanation of its
automated build process. The graded calculator adds modulus, exponentiation,
and square root to addition, subtraction, multiplication, and division.

Use `pyb run_unit_tests` in the calculator directory. Use `make all` in
`my_python_project` after installing PyBuilder. See the per-project READMEs
for virtual environment setup. All packages are built locally.
